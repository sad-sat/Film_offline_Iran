# Movie Streaming WebApp

## Overview
Client-side movie streaming catalog and player web application featuring a Netflix-inspired user interface, Trie-based autocomplete search, and video previews.

### Original Project Notes
- If you want to see the Netflix sliders and similar UI to build your own extended web app, this project serves as a reference implementation.
- Contains short 2-3 minute preview videos of movies and web series.
- **Live Preview:** https://nmovies.netlify.app/htmls/browse.htm
- **Demo Video:** https://www.youtube.com/watch?v=RRlS0xd9nHk&t=21s

## Subdirectories & Boundaries
- [JavaScript Layer](./js/README.md) - Client-side scripts for media streaming, JWPlayer video player setup, catalog data loading, and Trie autocomplete search
